## 两个必须知道的坑

1. **bundle patch 的新增行必须包在 `insert:` 下**。裸 `- id:/name:` 是"按 id 覆盖已有行"，组合里没这行就**静默不生效**——不报错、插件页显示"不包含任何组件"、模型回 `NO_TOOL`。这是本次卡最久的地方。
2. **手改 bundle 的 patch 文件不会通知运行中的 Host**。要么在插件页把开关**关→开**，要么重启 app。UI 的"刷新"只重读文件、不改活组合。
